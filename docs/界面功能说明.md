# SVS 签名验签 1.9.0 原型 - 侧栏「新」菜单界面操作流程

## 文档范围

本文基于项目当前界面逻辑整理，仅覆盖左侧菜单栏中带红色 **「新」** 角标的入口，不包含页内按钮、Tab 或其他位置的角标。

本项目为界面原型：列表、检测结果、配置保存等主要用于演示交互；部分数据写入浏览器本地存储，部分操作仅显示原型提示，不对接真实后端。

## 侧栏「新」菜单清单

| 上级菜单 | 菜单项 | 路由 | 页面定位 |
| --- | --- | --- | --- |
| 签名验签服务 | 密钥管理 | `/key/manage` | 0029 签名验签密钥 / 0019 通用密码容器 |
| 网络配置 | 接口管理 | `/network/interface` | 网口、子网口、聚合接口、VLAN、网桥 |
| 网络配置 | 路由配置 | `/network/route` | 静态路由维护 |
| 系统管理 | SNMP 管理 | `/system/snmp` | SNMP 服务、V3 用户、V2 开关 |
| 系统管理 | Syslog 配置 | `/system/syslog` | Syslog 服务器列表 |
| 系统管理 | 检测中心 | `/system/inspect` | 业务检测 / 设备自检 |
| 系统管理 | 系统配置 | `/system/config` | 接口鉴权 / 证书校验 |

说明：侧栏 **网络配置** 分组标题本身也带 **「新」** 角标，其下可进入页面为 **接口管理** 与 **路由配置**。

## 一、密钥管理

**进入路径**：左侧菜单展开 **签名验签服务**，点击 **密钥管理**。

进入后默认展示 **签名验签密钥** Tab；点击 **通用密码容器** 切换到 0019 容器管理，URL 同步为 `?tab=0019`；点击 **签名验签密钥** 回到 0029 面板。

### 1.1 签名验签密钥

1. 在筛选区按 **密钥 ID**、**密码算法**、**密钥用途**、**添加时间** 输入条件。
2. 点击 **查询** 过滤表格；点击 **重置** 清空筛选条件。
3. 查看列表中的密钥索引、密钥 ID、算法、用途、长度、添加时间及行内操作。
4. 点击 **生成密钥**，在弹窗中选择密钥类型并填写对应参数，点击 **确定**。
5. 生成成功后，页面提示成功，新密钥记录插入当前列表顶部。
6. 可继续使用行内 **详情**、**访问口令**、**备份**、**销毁** 等原型操作；涉及敏感信息的操作会走二次认证弹窗。
7. 点击 **恢复密钥** 可进入恢复流程，按弹窗要求填写或选择备份相关信息后确认。

### 1.2 通用密码容器

1. 点击 **通用密码容器** Tab。
2. 查看容器名、算法、用途、是否可导出、添加时间等列表信息。
3. 点击 **生成容器**，填写容器信息（含 **是否可导出**），点击 **确定**。
4. 生成成功后，新容器记录插入列表顶部。
5. 点击 **导入容器（UKEY）** 可演示导入流程；当前原型不把导入结果写入列表。
6. 行内可执行 **查看详情**、**UKEY 备份** 等操作；**是否可导出** 为 **否** 的容器，**备份** 按钮禁用，悬停可查看说明。

更完整的密钥管理细节见 [密钥管理-用户操作流程.md](./密钥管理-用户操作流程.md)。

## 二、接口管理

**进入路径**：左侧菜单展开 **网络配置**，点击 **接口管理**。

页面通过 Tab 管理多个接口类型；Tab 切换时面包屑会显示 `网络配置 / 接口管理 / 当前Tab`，URL 同步 `?tab=` 参数。

### 2.1 网口配置

1. 默认进入 **网口配置** Tab。
2. 查看接口别名、接口名、IPv4/IPv6 地址、子网掩码、网关、用途、网口状态、禁/启用状态。
3. 点击 **禁/启用** 开关，页面提示对应接口已启用或禁用。
4. 点击 **编辑** 打开 **接口编辑** 弹窗。
5. 在弹窗中选择用途：**管理网口** 或 **业务网口**。
6. 切换 **IPV4 / IPV6** 子 Tab，填写 IP 地址、子网掩码、网关。
7. 点击 **确定** 保存，页面提示 **接口配置已保存（原型演示）**。
8. 点击 **网口详情** 查看接口名称、启用状态、用途、IPv4、IPv6、厂商、版本、速率。

### 2.2 子网口

1. 切换到 **子网口** Tab。
2. 点击 **添加** 打开 **添加子接口** 弹窗。
3. 选择 **归属主接口**，设置 **禁/启用**，选择 **IP 类型**，填写 IP 地址、子网掩码。
4. 点击 **确定**，列表新增子接口并提示 **子接口已添加（原型演示）**。
5. 行内 **编辑** 当前为原型提示；点击 **删除** 后在确认框中确认删除。

### 2.3 聚合接口

1. 切换到 **聚合接口** Tab。
2. 点击 **添加** 打开 **添加聚合接口** 弹窗。
3. 填写 `bond.` 后缀编号，编号范围为 0-6。
4. 选择 bond 模式，勾选至少一个绑定网口。
5. 在 **IPV4 / IPV6** 子 Tab 中填写 IP 地址、子网掩码、网关。
6. 点击 **确定**，列表新增聚合接口并提示 **聚合接口已添加（原型演示）**。
7. 行内 **编辑** 当前为原型提示；点击 **删除** 后在确认框中确认删除。

### 2.4 VLAN

1. 切换到 **VLAN** Tab。
2. 点击 **添加** 打开 **添加VLAN** 弹窗。
3. 填写 `VLAN.` 后缀 ID，范围为 1-4094。
4. 选择 **关联接口**，设置 **禁/启用**。
5. 在 **IPV4 / IPV6** 子 Tab 中填写 IP 地址、子网掩码、网关。
6. 点击 **确定**，列表新增 VLAN 并提示 **VLAN 已添加（原型演示）**。
7. 列表中可切换 VLAN 启用状态；行内 **编辑** 当前为原型提示；点击 **删除** 后在确认框中确认删除。

### 2.5 网桥

1. 切换到 **网桥** Tab。
2. 页面默认展示系统网桥 `br0`；系统网桥可编辑但不显示删除操作。
3. 点击 **添加网桥** 打开 **添加网桥** 弹窗。
4. 填写 `br` 后缀编号，范围为 0-10，选择绑定网口，填写网关和子网掩码。
5. 点击 **确定**，列表新增网桥并提示 **网桥已添加（原型演示）**。
6. 点击 **编辑** 可修改绑定网口、网关、子网掩码；非系统网桥可点击 **删除** 并确认删除。

## 三、路由配置

**进入路径**：左侧菜单展开 **网络配置**，点击 **路由配置**。

1. 查看路由列表。表格字段包括 **IP 类型**、**路由类型**、**目的路由**、**子网掩码**、**网关**、**网络接口**、**状态**、**操作**。
2. 系统自动生成的系统路由不可勾选，行内 **编辑**、**删除** 按钮禁用。
3. 点击 **添加路由** 打开弹窗。
4. 选择 IP 类型，填写目的路由、子网掩码、网关，选择网络接口，设置启用/禁用状态。
5. 点击 **确定**，页面提示 **路由已添加（原型演示）**。
6. 对非系统路由点击 **编辑**，修改表单后点击 **确定**，页面提示 **路由已更新（原型演示）**。
7. 对非系统路由点击 **删除**，确认后删除该路由。
8. 勾选多条非系统路由后点击工具栏 **删除**，确认后批量删除。
9. 底部分页支持每页 10 / 20 / 50 条。

## 四、SNMP 管理

**进入路径**：左侧菜单展开 **系统管理**，点击 **SNMP 管理**。

1. 在页面顶部切换 **SNMP 服务状态** 开关。
2. 在 **SNMP版本_V3** 区域查看和维护用户列表。
3. 表格中可直接编辑用户名、安全级别、认证协议、认证密码、加密协议、加密密钥。
4. 点击 **添加用户** 在表格末尾新增一行空用户，填写后点击页面底部 **确定** 保存。
5. 点击行内 **编辑** 时，页面提示可直接在表格中修改字段并点击 **确定** 保存。
6. 点击行内 **删除**，确认 **确定删除该 SNMPv3 用户？** 后移除该行。
7. 在 **SNMP版本_V2** 区域切换 **启用SNMP_V2** 开关。
8. 点击 **确定**，页面提示 **SNMP 配置已保存（原型演示）**。

## 五、Syslog 配置

**进入路径**：左侧菜单展开 **系统管理**，点击 **Syslog 配置**。

1. 点击 **添加Syslog服务器**，表格顶部出现一行可编辑草稿。
2. 在草稿行填写 **Syslog服务器IP** 与 **Syslog服务器端口**。
3. 点击 **保存**。IP 需为合法 IPv4 或原型粗判 IPv6；端口需为 1-65535 的整数。
4. 校验通过后，页面提示 **保存成功（原型演示）**，草稿转为已保存记录。
5. 如草稿未保存，点击草稿行 **删除** 可放弃本次添加。
6. 已保存行只提供 **删除** 操作，点击后直接移除并提示 **已删除（原型演示）**。
7. 同一时间只允许一行未保存草稿；若已有草稿再次添加，页面提示 **请先保存或删除当前编辑行**。
8. 保存记录超过一页时，底部分页支持 10 / 20 / 50 / 100 条。

## 六、检测中心

**进入路径**：左侧菜单展开 **系统管理**，点击 **检测中心**。

进入后默认展示 **业务检测** Tab；点击 **设备自检** 切换设备检测列表，URL 同步为 `?tab=device`。

### 6.1 业务检测

1. 阅读页面顶部提示：检测前请上传 **CA 根证** 和 **证书管理** 里面的证书。
2. 点击证书输入框或右侧 **...** 按钮，打开证书选择弹窗。
3. 选择证书后确认，证书名称回填到输入框。
4. 点击 **开始检测**。未选择证书时按钮禁用，并提示需先选择证书。
5. 检测过程中按钮显示 **检测中...**，结果区展示进度和当前检测步骤。
6. 检测完成后，查看 **检测结果** 汇总和 **服务接口检测** 明细。检测项包括获取服务器证书、服务器签名、服务器验签、获取随机数、导出证书、数据签名、数据验签。
7. 点击结果区 **导出** 时，当前原型提示报告导出为占位能力。
8. 检测完成记录会写入检测历史；页面提示 **业务检测已完成**。

### 6.2 设备自检

1. 切换到 **设备自检** Tab。
2. 页面上方可按 **检测类型**、**检测结果**、**检测时间** 输入筛选条件。
3. 点击 **查询** 应用筛选；点击 **重置** 清空筛选。
4. 列表展示检测时间、检测类型、检测结果和 **详情** 操作；默认会补充一批设备自检演示记录。
5. 点击 **立即检测**，按钮显示 **检测中...**。
6. 检测完成后，系统生成一条手动检测记录，提示 **设备自检已完成**，并自动进入详情页。
7. 详情页展示 **基本信息**：自检时间、检测类型、检测结果。
8. 详情页 **检测内容** 表格展示 14 项检测：SM1、SM2、SM3、SM4、RSA、3DES、AES、SHA、内置密码卡状态、NTP、网络、硬盘、内存、CPU。
9. 点击 **导出检测报告** 下载 `.txt` 设备自检报告。
10. 点击详情页左上返回按钮，回到设备自检列表。
11. 点击 **自动检测** 打开 **自动检测设置** 弹窗。
12. 开启或关闭自动检测；开启时设置频率为每 N 分钟/小时/天执行一次。
13. 弹窗内点击 **立即检测** 会关闭弹窗并立刻发起一次设备自检。
14. 点击 **确定** 保存自动检测设置；开启时提示类似 **自动检测已开启：每 30 小时 执行一次**，关闭时提示 **已关闭自动检测**。

## 七、系统配置

**进入路径**：左侧菜单展开 **系统管理**，点击 **系统配置**。

进入后默认展示 **接口鉴权** Tab；点击 **证书校验** 切换证书校验配置，URL 同步为 `?tab=cert-validation`。

### 7.1 接口鉴权

1. 查看页面提示：本页为系统级接口鉴权通用策略，各应用接入凭证在 **应用管理** 中通过 **凭证** 查看。
2. 切换 **系统级接口鉴权** 开关。关闭时将弹出 **风险提示**，说明未授权访问风险，需点击 **确认关闭** 后才会关闭；取消则保持启用。
3. 查看 **鉴权方式**，当前固定为只读 **HMAC-SM3**。
4. 设置 **默认请求有效期**，取值范围为 1-60 分钟。
5. 点击 **保存配置**，页面提示 **系统接口鉴权配置已保存（原型演示）**。

### 7.2 证书校验

1. 点击 **证书校验** Tab。
2. 切换 **证书合法性校验** 开关。关闭时将弹出 **风险提示**，说明证书合法性校验将被关闭的安全风险，需点击 **确认关闭** 后才会关闭；取消则保持启用。
3. 鼠标悬停问号可查看说明：关闭后将关闭用户验签时的 CA 有效期、CA 证书链、吊销列表等合法性校验。
4. 点击 **保存配置**，页面提示 **证书校验配置已保存（原型演示）**。
